# Gold-Price-Analysis
Interactive Streamlit app for analyzing historical gold prices, calculating profit/loss over custom time ranges, and forecasting future prices using linear regression.

This project is ideal for beginners in data analytics, machine learning, and financial data visualization. It is an interactive Streamlit application that loads historical gold price data from a CSV file, automatically detects and processes date columns, calculates profit or loss percentages between user selected years, and forecasts future gold prices up to a chosen year using a Linear Regression model. The application visualizes actual versus predicted gold price trends and displays forecasted prices in a tabular format, with interactive sidebar controls for user input.

The project is built using Python with Streamlit as the web framework, Pandas and NumPy for data processing, Matplotlib for data visualization, and Scikit-learn for implementing the Linear Regression model. The dataset must be named gold_price.csv, contain a date column (any column containing the word “date” is auto-detected), and include a gold price column named USD (PM).

To set up the project, clone the repository, navigate to the project directory, optionally create and activate a virtual environment, install the required dependencies (streamlit, pandas, numpy, matplotlib, scikit-learn), and place the gold_price.csv file in the project root directory. Run the application using streamlit run gold_price_analysis.py, after which the app will open automatically in your browser.

Internally, the application loads and cleans the dataset, validates date and price columns, calculates percentage returns and profit or loss, trains a Linear Regression model on historical data, predicts future prices based on yearly trends, and presents the results through interactive charts and tables. The forecasting approach uses a simple linear regression model and does not account for real-world economic factors, so the project is intended strictly for educational and learning purposes, not financial advice. Future improvements may include advanced forecasting models such as ARIMA or LSTM, support for multiple commodities, CSV upload through the UI, finer-grained forecasting, and improved model evaluation metrics
